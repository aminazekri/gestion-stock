# Stock - Gestion de stock en PHP

**Groupe :**AMIBA

Application PHP en ligne de commande qui gère le stock d'un magasin
(produits, quantités, valeur du stock, commandes).

## Contrat d'interface

- **A - Produit** : constructeur(reference, nom, prix, quantite = 0), getters, ajouterQuantite, retirerQuantite, valeurStock
- **B - Stock** : ajouter, trouver, tous, compter, valeurTotale, produitsEnRupture, produitsSousSeuil
- **C - Commande** : constructeur(numero), ajouterLigne, total, valider, estValidee, afficher + index.php
